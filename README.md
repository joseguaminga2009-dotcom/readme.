# PokéAPI Dashboard

Aplicación web interactiva que consume la PokéAPI para explorar Pokémon, ver detalles en tiempo real y gestionar una lista de favoritos.

## Características
- **Dashboard:** Galería responsiva con paginación de 20 en 20.
- **Detalles en Pop-up:** Ventana modal con imagen, tipos, peso, altura y estadísticas básicas.
- **Sistema de Favoritos:** Guarda y quita favoritos persistidos en `localStorage`.
- **Diseño Responsivo:** Adaptado para dispositivos móviles y de escritorio.

## API Utilizada
- [PokéAPI](https://pokeapi.co/)

## Cómo ejecutar el proyecto
1. Clona o descarga este repositorio.
2. Abre el archivo `index.html` en cualquier navegador web.
